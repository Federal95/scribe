# Scribe

Scribe est un outil de prise de notes intelligent.

Il permet de :

- transcrire un fichier audio grâce à Groq Speech-to-Text ;
- générer automatiquement un compte rendu structuré grâce à un LLM.

## Installation

Créer un environnement virtuel :

```bash
python -m venv venv
```

Activer l'environnement :

Windows :

```bash
venv\Scripts\activate
```

Installer les dépendances :

```bash
pip install -r requirements.txt
```
